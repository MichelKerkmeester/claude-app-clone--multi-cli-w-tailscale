## Recommended 007-extension approach

The unifying safety fact, verified in three critiques against `scripts/token-identity.mjs`: it strips all comments and diffs only custom-property (`--*`) resolved values across the 3 themes. So **comment-only edits are provably invisible to it** — but it is equally blind to markup whitespace, `<style>` whitespace reflow of normal declarations, `content:` strings, selector combinators, and guardrail-fence *content*. The `>=76` fence gate proves count, not verbatimness. Therefore 007-ext holds to **comments + prose docs + non-emitting config only** — no CSS/markup reflow, no rule deletion, no bulk formatter — and adds a per-file unchanged-fence-*text* diff on the ~39 fence-bearing files to close the count-vs-content gap.

**(a) Inline comments.** Author the 4-element house grammar as ONE short reference (file-header purpose line; WHY-not-what inline; the existing `@ds surface/state/slot/variant/edit/guardrail` markers; one-line TSDoc on exports only) — this is the 008 payload, zero source change. Then, comment-only: tag the **26 genuinely marker-less** `.svelte` files (header in the top `<script>`, NEVER in `<style>` — scope-hash risk), backfill the 6 missing `// MODULE:` banners, add TSDoc to exports under `shared/data`, and collapse triplicated `@ds surface:` to **once-per-surface-per-file** (not once-per-file — that breaks the 4-surface god-files). Do NOT roll a new header across the 69 files that already self-announce via `@ds surface`.
*Gate:* `build` + `svelte-check` (syntax-only failures) + `token-identity` 0-diff ×3 (comment-blind ⇒ proves no value moved) + per-file fence-text diff + `test:web`.

**(b) Architecture.** Three items, no layout change. (1) Add a single `$shared` alias (drop `$primitives`/`$data`) and run a scripted, deterministic codemod over the 168 deep-relative specifiers (preserve the `.js` extension on `.ts` targets). Hard prerequisite: the alias must be wired in lockstep in `svelte.config.js` kit.alias **and both** `vitest.web.*.config.ts` `resolve.alias` **and** the Storybook builder — the test configs use plain `svelte()` with no `sveltekit()`, so without this the codemod reds `test:web`. (2) Prune the dead React `compilerOptions` (`jsx`, `jsxImportSource`, `allowJs`), the `src/lib/**` include, and the false migration comment from `tsconfig.json`. (3) Preserve the proposal's anti-scope-creep policing verbatim (no god-file splits, no barrels, no renames, no dual-`chrome/` rename).
*Gate (alias):* FULL board — `build` + `svelte-check` + `test:web` + `token-identity` 0-diff ×3 + **CDP 390px both themes** + `catalog-smoke` (a mass specifier rewrite is the one place a rendered value could silently move via wrong resolution). *Gate (tsconfig):* `svelte-check` error-count byte-identical before/after + `build` (prove by count delta — the include-override rationale in the proposal is wrong; the empirical guard does the work).

**(c) Styling structure.** All comment-only, no rule moved or reordered: one owner-pointer anchor at each orphaned `app.css` surface (rules now live in a scoped `<style>`); relocate the `@ds` legend to the top of `app.css` with a pointer replacing the `catalog-registry.ts` copy (trimmed to a marker/pointer legend — the token-tier primer goes to 009, not a second drifting home); a single 3-pass index atop the scattered artifact-viewer blocks; repair stale `.tsx`→`.svelte` / `SafeMarkdown.tsx` refs and add one line explaining the **live** `.react-aria-*` shim (trace the real producer before rewording — never touch a `.react-aria-*` selector or a `data-*` attribute name); fix the misplaced `@ds end surface` (L3150), the L1220 dup, and the verbatim-repeated blocks. Section banners only in the 4 god-files + `app.css`, not all 66 style-bearing files.
*Gate:* `token-identity` 0-diff ×3 + contrast + **CDP 390px both themes** (backstop, since token-identity is comment/whitespace-blind — the "comment-only, no reflow" discipline is what makes the proof sufficient) + fence count + fence-text diff.

**(d) Editing ease.** Rewrite the 4 stale React onboarding docs (root `README`, `ARCHITECTURE.md`, `app-mobile/README.md`, `app-mobile/src/README.md`) to Svelte reality — re-derive the actual surviving module map (`relay.ts`/`auth.ts`/`attention.ts` likely survive; `App.tsx`/`state.ts`/reducers do not; naive find/replace fabricates false claims) and refresh `trigger_phrases`; make `src/README.md` the canonical **route→folder→file screen map** (resolve the two-lenses-one-file collision by giving the screen map to `src/README.md` and the high-level to `ARCHITECTURE.md`). Add `.vscode/{extensions,settings}.json`, an `.editorconfig` (2-space — the durable fix for the 2 tab-indented primitives; hand-normalizing drifts back), install `prettier-plugin-svelte` for format-on-save **going forward only** (NOT a bulk reflow), delete the orphaned `catalog.html` (confirm it is not a Vite input) and the 3 retired oracle scripts (`build-app-css.mjs`, `css-corpus-equivalence.mjs`, `decl-equivalence.mjs`; also fix the dangling "Mirrors decl-equivalence.mjs" comment in `tests/support/css-corpus.ts`), and add a root `npm run storybook` (drop `--no-open`).
*Gate:* `build` + `format:check` + `build-storybook` exit 0 + `catalog-smoke` light+dark; editor config is unshipped (no gate).

## Scoping & sequencing

Phase **per-dimension, risk-ascending** (not per-surface — that fragments the cross-file grammar and re-pays gates N times; not one-pass — that unlocalizes gate failures). Fold the sequencing lens's E1+E2 together (same gate signature) but keep the alias isolated as its own risk class.

- **Phase 0 — Calibrate & Logic-Sync (Claude-only, no edits).** Re-measure the census (the sequencing lens's counts ran 1.5–2.4× off; dead `style.css` refs are ~86 unique lines/59 files, not ~150) and confirm the 26 marker-less files + fence inventory before staffing. **Flag the contradiction:** the DX lens found `commands.ts` and `runtime.ts` still statically import `react` with dead hooks — this contradicts the frozen "React fully deleted" invariant. Verify; if real it is **007-cutover completion work (and the real 009 blocker), not this DX re-host** — escalate for an amendment decision, do not silently fold it in. *Barrier:* findings confirmed against the tree.
- **Phase A — Docs, config hygiene, dead-file removal (no source/style bytes).** All of dimension (d) plus the `tsconfig` prune. *Barrier:* `build` + `svelte-check` (+ error-count delta for tsconfig) + `test:web` + `format:check`.
- **Phase B — Comment grammar + wayfinding (comment-only source edits).** All of (a) and (c), plus the dead `style.css`-reference purge. *Barrier:* `build` + `svelte-check` + `token-identity` 0-diff ×3 + contrast + CDP 390px both themes + `>=76` fence count + **per-file unchanged-fence-text diff** + `test:web`. No markup/CSS whitespace reflow permitted.
- **Phase C — `$shared` alias + codemod (highest execution risk, isolated, severable).** Dimension (b) item 1. *Barrier:* the FULL board above including CDP + `catalog-smoke`. If the multi-resolver sync surface is judged too much for a re-host, this phase defers cleanly without blocking A/B.

## Executor split & verification

Per the source-fix dispatch policy, mechanical app-source edits are executor-written (cli-pi / deepseek-v4-flash xhigh + code persona) and Claude owns barriers + independent verification. The WS-B lesson governs: executors mask by weakening/deleting code, so Claude diff-inspects that **only comment/whitespace lines changed** before trusting any gate.

**Executor-written → Claude diff-inspects (comment-only) → gate:**
- Phase B bulk mechanicals: dead-`style.css` purge, owner-pointer anchors, marker-less-file tagging, MODULE-banner backfill, export TSDoc, residue fixes, god-file/`app.css` section banners. *Proof:* comment-only ⇒ `token-identity` 0-diff is dispositive; fence-text diff proves no fence altered.

**Claude-only (judgment or barrier):**
- The react-aria WHY-vs-history discrimination — **no gate protects it**; a misclassified deletion reintroduces the touch-sticky a11y regression later. Executors must not delete `.sel:global([data-*])` WHY comments.
- The 4-element grammar reference; the `@ds` legend relocation; the honest "unstyled primitive — styled by the consumer `class` prop" one-liner (the primitives have no CSS home to point at).
- All docs (re-derive the real module map), `tsconfig` prune, `.vscode`/`.editorconfig`, `catalog.html` + oracle-script deletion, root storybook script, 009 spec refresh.
- Phase C entirely: resolver wiring (4 sites), the deterministic codemod script, and full-board verification. *Proof:* CDP 390px both themes + `token-identity` catch any specifier that resolves to a different module.

## Sequencing into 008 and 009

**008 (sk-code conventions skill)** encodes the grammar Phase B *decides* — it must not re-invent it (drift risk). Payload: the 4-element comment grammar; `$shared`-not-deep-relative imports; one-file-per-component; the `*.svelte.ts` factory + Symbol-key context pattern; the CSS ownership-routing rule (single→scoped, shared→`app.css :global`, cross-boundary state→parent `:global(.child)`); `:global` only for theme-remap and `[data-*]` state; headers-in-`<script>`-never-`<style>`; comment-hygiene (no artifact ids, no stale-`.tsx` refs); and the anti-scope-creep policing (no god-file splits, no barrels, no renames — do NOT enshrine 1700-line files as "the convention"). 008's objective gate is the ONE surviving slice of the enforcement idea: **extend the existing (PostToolUse-wired) comment-hygiene hook to reject any `@ds` keyword outside the legend's allowed set** — no new eslint/TSDoc toolchain.

**009 (self-maintaining Storybook)** gets its coverage taxonomy for free from Phase B: the `@ds surface:` file-header = the story-per-surface coverage key; `@ds primitive:` / `@ds route:` tags = the legitimately story-exempt allowlist. What must land in 007-ext for 009 to succeed: (1) the marker taxonomy above; (2) accurate 009 spec frontmatter — mark ONLY the `style.css→app.css` and stories-co-located preconditions met, keep the React-delete blocker honest; (3) the root `npm run storybook` script; (4) resolution of the `commands.ts`/`runtime.ts` React residue (the real blocker). 009 does NOT get new stories written in 007-ext — 009 owns the story convention, and premature stories force the codemod-over-new-stories rework its own spec warns of.

## Deferred / rejected

- **eslint/svelte-check TSDoc-presence rule** — no eslint exists and svelte-check can't enforce doc presence; standing up a toolchain is process-heavy for a re-host. Only the `@ds`-keyword hook extension survives.
- **Duplicate fence-count gate + legend-sync gate + blocking file-header mandate** — redundant with the existing `>=76` gate / invented / cargo-culted build-failure.
- **Bulk `prettier-plugin-svelte` reflow** — token-identity is blind to markup whitespace and fenced-byte content; reflowing rendered text nodes and do-not-edit fences is a byte-identity HARD STOP. Plugin installed for format-on-save going forward only.
- **eslint-plugin-svelte + de-React eslint swap** — the "dead config" premise is false (react-hooks fires on live `commands.ts`/`runtime.ts`; the `.tsx` glob matches 9 real test files) and it invites a lint-fix wave. Defer to a tooling task.
- **Deleting the 10 empty `@keyframes` stubs** — only rule change in the set, lowest value, one owner mis-attributed (`model-header-accepted` is `SessionHeader.svelte`). Annotate-pointer instead, or defer to post-009 with per-keyframe grep-across-all-src + CDP.
- **`$primitives`/`$data` aliases** — `$shared` alone serves the designer; extra alias surface is premature granularity across 4 resolvers.
- **Flatten `pages/chat/features/ask-question`** — gold-plating churn; the proposal itself calls it low-value.
- **God-file splits (ModelEffortSheet/SessionComposer/ArtifactViewerHost/TodoPanel)** — redesign, not re-host; touches a11y focus-trap + rendered values. Sectioning gets ~90% of navigability at zero risk; splits are a gated post-cutover amendment.
- **Physical CSS refactors (011 literal→token, 012 overlay-primitive, 014 status-badge)** — value-edit refactors, post-009 optimization track.
- **`:global` reduction / property-order enforcement** — cargo-culting; `:global` is the faithful theme-remap/`[data-*]` pattern.
- **Barrels, factory renames, dual-`chrome/` rename** — churn > value; hurt locate / parent path already disambiguates.
- **Standalone EDIT MAP doc** — triplicates 008 (machine twin) and the corrected README (human twin); record the decided grammar there + in spec/handover.
- **`@ds styled-by:` pointers on primitives** — misdiagnosis; they are intentionally unstyled pass-throughs, replaced by the honest one-liner.
- **Blanket "009 ready" flip** — the React-delete blocker is genuinely unmet; mark only the structural preconditions.
